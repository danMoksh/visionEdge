# Security Policy

## Supported Versions

Security updates are provided for active deployments on the default branch.

| Version | Supported          |
| :------ | :----------------- |
| Latest  | Yes |
| < 1.0   | No                |

## Reporting a Vulnerability

If you discover a potential security vulnerability regarding the FOD detection pipeline, telemetry endpoints, or rover communication channels, please report it responsibly:

1. **Do not open public GitHub issues** to report potential security flaws.
2. Submit your report privately through **[GitHub Security Advisories](https://github.com/danMoksh/visionEdge/security/advisories/new)** or email **mokshdandotiya@gmail.com**.
3. Please provide:
   - A detailed explanation of the issue
   - Minimal reproduction commands or scripts
   - System environment details (OS, Python, ROS version)

## Response SLA

- **Acknowledgement**: Within 48 hours
- **Triage**: Within 5 business days
